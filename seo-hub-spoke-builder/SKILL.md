# SEO Hub & Spoke Builder

Build a Topical Authority Cluster for a core topic. Google needs to see you as the expert on the entire subject — not just one query. One entity, ten angles.

## Input Required

1. **Core topic** — e.g. "Enterprise CRM", "Home Insurance", "Sourdough Bread"
2. **Business context** *(optional)* — what you sell or offer, so spoke topics align with commercial intent
3. **Existing content** *(optional)* — list of URLs already published, to avoid cannibalization

---

## Output: Hub & Spoke Content Map

### The Hub Page

Define the ultimate guide — the single authoritative page that owns the topic.

- **Recommended H1** — written for humans, includes the primary entity, under 60 chars
- **User intent** — what someone searching this topic ultimately wants to accomplish
- **Recommended word count** — comprehensive enough to be the definitive resource
- **Key entities to establish** — the concepts, brands, people, and frameworks this page must mention to be seen as authoritative

---

### The 10 Spoke Articles

Generate 10 spoke titles that support the Hub. Each spoke must:
- Cover a **distinct search intent** (no cannibalization with Hub or other spokes)
- Be semantically related to the core topic
- Target a real audience need — not a keyword-stuffed variation

Intents to cover across the 10 spokes:
- **How-to / Tutorial** (2 spokes)
- **Comparison / Best X for Y** (2 spokes)
- **Common Mistakes / What to Avoid** (1 spoke)
- **Trends / Future of** (1 spoke)
- **Beginner / What is** (1 spoke)
- **Advanced / Expert** (1 spoke)
- **Case Study / Real-world example** (1 spoke)
- **Commercial / Buyer-intent** (1 spoke)

---

### Output Table

| # | Spoke Title | Target Keyword | User Intent | H2 #1 | H2 #2 | H2 #3 | Internal Link to Hub |
|---|---|---|---|---|---|---|---|

H2 headers must:
- Use NLP-friendly terms related to the core entity
- Cover the topic from a different angle than the Hub
- Help Google understand this page as a *supporting* piece, not a competitor

---

## Internal Linking Instructions

After the table, provide:

**Hub → Spoke links:** Which sections of the Hub should link out to each Spoke (and with what anchor text)

**Spoke → Hub links:** Where in each Spoke article to place the link back to the Hub (recommended placement: within first 300 words and once more near the conclusion)

**Spoke → Spoke links:** Any natural topical connections between spokes worth cross-linking

---

## Notes

- Flag any spoke that risks cannibalization with the Hub — resolve by adjusting scope or merging
- If the user provided existing content URLs, check each against the map and note which spokes already exist (update vs. create)
- The Hub should not be a product/service page. It is informational authority content that funnels to commercial pages via internal links
